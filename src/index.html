Guarde estas 12 palavras

Só você deve ver estas palavras. Qualquer pessoa com a frase ou com a chave hexadecimal e um backup do cofre pode recuperar os dados. A frase NÃO é compatível com carteiras Bitcoin.

Imprima o PDF ou guarde-o em um cofre seguro. NÃO coloque em serviços de nuvem sem proteção. Faça também um backup completo do cofre. As palavras não serão exibidas novamente após fechar esta janela; para mudar será necessário criar outras.
